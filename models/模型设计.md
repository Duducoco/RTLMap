# 双图覆盖率回归模型设计

## 1. 任务目标

模型目标是根据 RTL CDFG 和测试对应的 ASM CDFG，预测模块级覆盖率：

```text
branch, line, fsm, toggle, condition
```

当前训练目标是图级覆盖率回归，不再训练 RTL 边覆盖分类任务。

## 2. 输入与输出

输入：

- RTL CDFG：节点类型、cell type、位宽、边类型、边宽、端口位置等结构特征。
- ASM CDFG：基本块类型、指令编码、控制/数据依赖边。
- 图级覆盖率标签：`targets.graph_coverage`。
- joint contrastive 模式额外使用：`targets.coverage_vectors`。

输出：

- `graph_pred: [B, num_coverage_targets]`
- `hyper_min/hyper_max: [B, 5, D_box]`，五种 coverage type 各自对应可配置维度的子矩形。

模型不输出 `edge_logits`，也不计算边分类损失。

## 3. 总体结构

```text
RTL CDFG ──┐                              ┌── GraphRegressor ── graph_pred
           ├── PerceiverDualEncoder ── concat(rtl_graph, asm_graph)
ASM CDFG ──┘                              └── HyperrectangleHead ── hyper_min / hyper_max
```

设计要点：

- RTL 和 ASM 分别编码。
- ASM 作为测试激励上下文，通过跨图融合影响 RTL 表示。
- 回归头和几何头都直接使用 RTL 与 ASM 图级表示。
- RTL 边类型、边宽、端口位置仍作为结构特征参与消息传递，但不作为分类目标。

## 4. 图级覆盖率回归

对每个覆盖率目标维护独立 MLP head：

```text
graph_pred[k] = CoverageHead_k(concat(rtl_graph, asm_graph))
```

监督损失：

```text
L_graph = SmoothL1(graph_pred[valid], target[valid])
```

`target` 中的 `NaN` 表示该覆盖率类型缺失，训练时会被 mask。

总监督损失：

```text
L_total = L_graph
```

## 5. Joint Contrastive

joint contrastive 使用普通 `dataset.v1` 样本构造同模块 `(a, b)` pair。

覆盖空间按固定类型顺序分块：

```text
line, condition, toggle, fsm, branch
```

每种类型的覆盖密度和 Jaccard：

```text
density_type(a) = |Covered_type(a)| / element_count_type
similarity_type(a, b) = |Covered_type(a) ∩ Covered_type(b)|
                        / |Covered_type(a) ∪ Covered_type(b)|
```

子矩形真实体积监督为 `density_type`，子矩形真实体积 IoU 监督为
`similarity_type`。共同未覆盖的 0/0 不贡献相似度。

joint loss：

```text
L_total = lambda_ce * (L_graph(a) + L_graph(b)) / 2
        + lambda_iou * (L_iou_calibration + w_rank * L_iou_rank)
        + warmed_lambda_volume * L_volume
```

## 6. 关键设计决策

| 设计点 | 当前选择 | 理由 |
|---|---|---|
| 预测目标 | 图级覆盖率回归 | 与覆盖报告级监督对齐 |
| 边级标签 | 不训练 | 当前方案用覆盖向量相似度，不再需要边分类任务 |
| ASM 用途 | 编码上下文 | 表示测试激励对 RTL 的影响 |
| RTL 边特征 | 参与编码 | 保留电路结构与端口语义 |
| 对比目标 | covered-set positive Jaccard | 关注共同覆盖元素，避免共同 0 主导 |
| 覆盖空间 | 每类型五维真实体积子矩形 | log 体积表达覆盖密度，IoU calibration 与 ranking 表达 Jaccard |

## 7. 参数规模

模型参数主要来自：

- RTL/ASM 编码器
- Perceiver 跨图融合
- 多覆盖率 `GraphRegressor`
- 可选 `HyperrectangleHead`

删除边分类 head 后，参数和训练目标都集中在图级覆盖率预测与对比学习。
