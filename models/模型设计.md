# 双图融合神经网络架构设计

## 1. 模型概述

**任务目标**：模拟"汇编测试激励在 RTL 硬件上执行"的过程，预测 RTL CDFG 边的覆盖状态。

**核心设计理念**：
- **编码阶段**：RTL 和 ASM 通过跨图注意力交互，相互增强表示
- **预测阶段**：仅使用 RTL CDFG 进行边分类和图回归
- ASM CDFG 作为上下文信息，帮助模型理解"测试激励如何影响硬件"

**输入**：
- RTL CDFG：$G_{rtl} = (V_{rtl}, E_{rtl}, X_{rtl}, T_{rtl}^e)$
- ASM CDFG：$G_{asm} = (V_{asm}, E_{asm}, X_{asm}, T_{asm}^e)$

**输出**（仅基于 RTL）：
- 边级预测：$\hat{y}_e \in \{0, 1\}$（未覆盖/已覆盖），label=-1 的边被 mask
- 图级预测：$\hat{c} \in [0, 1]$（覆盖率）

## 3. 核心模块详解

### 3.1 边类型嵌入 (Edge Type Embedding)

CDFG 中边类型携带关键语义信息：

| 索引 | 边类型 | 语义描述 |
|:----:|:------:|:---------|
| 0 | DATA | 数据流边，表示数据传输 |
| 1 | CONTROL | 控制流边，表示条件分支 |
| 2 | CLOCK | 时钟边，连接时钟信号 |
| 3 | RESET | 复位边，连接复位信号 |
| 4 | ENABLE | 使能边，连接使能信号 |

**嵌入方式**：
$$\mathbf{e}_{rtl,i} = \text{Embedding}_{rtl}(t_i) \in \mathbb{R}^{d_h}, \quad t_i \in \{0,1,2,3,4\}$$
$$\mathbf{e}_{asm,i} = \text{Embedding}_{asm}(t_i) \in \mathbb{R}^{d_h}, \quad t_i \in \{0,1,2,3,4\}$$

**设计选择**：RTL 和 ASM 使用独立的边类型嵌入，因为两种 CDFG 的边类型语义可能存在差异。

**使用位置**：
1. GINEConv 消息传递（RTL 和 ASM 使用各自的嵌入）
2. EdgeClassifier 分类输入（仅 RTL，使用独立的边类型嵌入）

---

### 3.2 GNN Layer (GINEConv)

单层图神经网络，支持边特征：

```
Input: (x, edge_index, edge_attr)
       │
       ▼
┌──────────────────────────────────┐
│  GINEConv                        │
│  h_v = MLP(x_v + Σ ReLU(x_u + e_uv))  │
│                                  │
│  MLP: Linear(d) → GELU → Linear(d)    │
└──────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────┐
│  DropPath (Stochastic Depth)     │
│  p_l = p_base × l / (L-1)        │
└──────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────┐
│  Residual + LayerNorm            │
│  output = LayerNorm(x + h)       │
└──────────────────────────────────┘
       │
       ▼
Output: x' ∈ ℝ^{N×d}
```

**数学表达**（RTL 和 ASM 各有独立参数 $\theta_{rtl}$, $\theta_{asm}$）：
$$\mathbf{h}_v^{(l)} = \text{MLP}^{(l)}_{\theta}\left(\mathbf{x}_v^{(l)} + \sum_{u \in \mathcal{N}(v)} \text{ReLU}(\mathbf{x}_u^{(l)} + \mathbf{e}_{uv})\right)$$

$$\mathbf{x}_v^{(l+1)} = \text{LayerNorm}\left(\mathbf{x}_v^{(l)} + \text{DropPath}(\mathbf{h}_v^{(l)})\right)$$

---

### 3.3 跨图交互 (CrossGraphInteraction)

双向跨图注意力，RTL 和 ASM 共享同一个注意力模块：

```
┌─────────────────────────────────────────────────────────────┐
│                  CrossGraphAttention                         │
│                                                             │
│  Input: query [B, N_q, d], key_value [B, N_k, d]            │
│                                                             │
│  1. Pre-LayerNorm                                           │
│     q_norm = LayerNorm(query)                               │
│                                                             │
│  2. Multi-Head Attention                                    │
│     Q = W_q · q_norm    [B, N_q, H, d/H]                   │
│     K = W_k · key_value [B, N_k, H, d/H]                   │
│     V = W_v · key_value [B, N_k, H, d/H]                   │
│                                                             │
│     Attn = softmax(Q·K^T / √(d/H)) · V                     │
│     out = W_o · Attn                                        │
│                                                             │
│  3. Gated Residual                                          │
│     gate = σ(W_g · [query ‖ out])  ∈ (0,1)  ← 标量门控     │
│     output = query + gate × out                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**双向交互**（共享同一个 Attention 模块）：
$$\mathbf{H}_{rtl}' = \text{CrossAttn}(\mathbf{H}_{rtl}, \mathbf{H}_{asm})$$
$$\mathbf{H}_{asm}' = \text{CrossAttn}(\mathbf{H}_{asm}, \mathbf{H}_{rtl})$$

---

### 3.4 边分类器 (EdgeClassifier)

**仅使用 RTL CDFG**，融合源节点、目标节点和边类型信息，**二分类**：

```
Input: rtl_node_features [N₁, d], rtl_edge_index [2, E₁], rtl_edge_type [E₁]
       │
       ▼
┌──────────────────────────────────┐
│  Feature Extraction              │
│  src_feat = rtl_node[src]        │
│  tgt_feat = rtl_node[tgt]        │
│  edge_feat = Embedding(edge_type)│
└──────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────┐
│  Concatenation                   │
│  x = [src_feat ‖ tgt_feat ‖ edge_feat]  │
│  x ∈ ℝ^{E₁ × 3d}                 │
└──────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────┐
│  MLP Classifier                  │
│  Linear(3d → d) → GELU → Dropout │
│  Linear(d → 2)                   │
└──────────────────────────────────┘
       │
       ▼
Output: logits [E₁, 2] → {0: 未覆盖, 1: 已覆盖}
        (训练时 mask 掉 label=-1 的边)
```

---

### 3.5 图回归器 (GraphRegressor)

**仅使用 RTL CDFG 图嵌入**：

```
Input: rtl_graph_emb [B, d]
       │
       ▼
┌──────────────────────────────────┐
│  MLP Regressor                   │
│  Linear(d → d) → GELU → Dropout  │
│  Linear(d → 1)                   │
└──────────────────────────────────┘
       │
       ▼
Output: coverage [B, 1] → [0, 1]
```

## 5. 超参数配置

| 参数 | 符号 | 默认值 | 说明 |
|:-----|:----:|:------:|:-----|
| RTL 节点输入维度 | $d_{in}^{rtl}$ | 64 | RTL 节点特征维度 |
| ASM 节点输入维度 | $d_{in}^{asm}$ | 64 | ASM 节点特征维度 |
| 隐藏层维度 | $d_h$ | 256 | 编码器隐藏维度 |
| GNN 层数 | $L$ | 4 | 编码层数量 |
| 注意力头数 | $H$ | 4 | 多头注意力头数 |
| DropPath 概率 | $p_{base}$ | 0.1 | 随机深度基础概率 |
| 边类型数量 | $\|T\|$ | 5 | DATA/CONTROL/CLOCK/RESET/ENABLE |
| 边分类类别 | $C$ | 2 | {0, 1}，-1 被 mask |
| Label Smoothing | $\epsilon$ | 0.1 | 标签平滑系数 |

## 6. 损失函数

**边分类损失**（带 Label Smoothing，仅 RTL 有效边，mask 掉 label=-1）：
$$\mathcal{L}_{edge} = \frac{1}{|\mathcal{E}_{valid}|} \sum_{e \in \mathcal{E}_{valid}} \text{CE}(\hat{y}_e, y_e), \quad \mathcal{E}_{valid} = \{e | y_e \neq -1\}$$

**图回归损失**（仅 RTL 图）：
$$\mathcal{L}_{graph} = \text{SmoothL1}(\hat{c}^{rtl}, c^{rtl})$$

**总损失**：
$$\mathcal{L} = \alpha \cdot \mathcal{L}_{edge} + \beta \cdot \mathcal{L}_{graph}$$

默认：$\alpha = 1.0, \beta = 1.0$

## 7. 关键设计决策

| 设计点 | 选择 | 理由 |
|:-------|:-----|:-----|
| GNN 类型 | GINEConv | 支持边特征，表达能力强 |
| GNN 参数 | RTL/ASM 独立 | 两种 CDFG 语义不同，独立学习更灵活 |
| 边类型嵌入 | RTL/ASM 独立 | RTL 和 ASM 边类型语义可能存在差异 |
| 正则化 | DropPath | 比 Dropout 更稳定，逐层递增 |
| 归一化 | Pre-LayerNorm | 训练更稳定 (Xiong et al., 2020) |
| 跨图交互 | 共享参数 | 作为连接两图的桥梁，减少过拟合 |
| 门控机制 | 标量 Sigmoid | 简化设计，减少参数 |
| 预测阶段 | 仅 RTL | ASM 仅作为编码上下文 |
| 边分类输入 | src‖tgt‖edge_type | 融合节点和边信息 |
| 边分类 mask | label=-1 的边 | 仅对有效边计算损失 |
| 图回归输入 | rtl_graph | 仅 RTL 图级表示 |
| 损失函数 | Label Smoothing | 防止过拟合 |
