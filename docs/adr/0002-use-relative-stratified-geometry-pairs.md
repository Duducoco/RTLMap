# Use relative-stratified geometry pairs

RTLMap will train known-module, new-stimulus geometry with deterministic per-epoch Geometry Pair resampling rather than manifest-neighbor pairs. Each valid sample acts as an anchor, draws up to 128 same-module candidates, and requests two relative-low, one relative-mid, and one relative-high partner from anchor-local similarity quartiles; duplicate unordered pairs are repaired within the same stratum, and an exhausted stratum may leave the quota partially unfilled. This relative policy gives every module useful pair diversity without imposing absolute Jaccard thresholds that do not fit all modules.

Graph regression and density-volume supervision remain in pair batches. Each endpoint-local loss is weighted by mean pair degree divided by its sampled degree, independently within each Coverage Type, so repeated partner selection does not change the intended type-equal supervision; pair-local IoU loss remains uniform over unique Geometry Pairs. Samples with zero pair degree do not participate in joint training. Training pairs use `seed + epoch`; validation pairs use a fixed seed and report aggregate geometry metrics. Train/validation splitting keeps every dataset-local `test_id` intact so validation measures new Test Stimuli for modules already represented during training. The new sampler configuration replaces the manifest-neighbor options without a compatibility alias.
