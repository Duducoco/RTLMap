# Use relative-stratified geometry pairs

RTLMap will train known-module, new-stimulus geometry with deterministic per-epoch Geometry Pair resampling rather than manifest-neighbor pairs. Each valid sample acts as an anchor, draws up to the configured number of same-module candidates (256 in the training script), and requests two relative-low, one relative-mid, and one relative-high partner from anchor-local similarity quartiles. If any candidate has a coverage signature different from the anchor, identical-signature candidates are removed before pool truncation and stratification; the sampler falls back to identical signatures only when no informative candidate exists. Duplicate unordered pairs are repaired within the same stratum, and an exhausted stratum may leave the quota partially unfilled. This relative policy gives every module useful pair diversity without imposing absolute Jaccard thresholds that do not fit all modules.

Graph regression and density-volume supervision remain in pair batches. Each endpoint-local loss is weighted by mean pair degree divided by its sampled degree, independently within each Coverage Type, so repeated partner selection does not change the intended type-equal supervision. Pair-local IoU calibration and ranking give each defined Coverage Type equal weight. Samples with zero pair degree do not participate in joint training. Training pairs use `seed + epoch`; validation pairs use a fixed seed and report aggregate geometry metrics. Train/validation splitting keeps every dataset-local `test_id` intact so validation measures new Test Stimuli for modules already represented during training. The new sampler configuration replaces the manifest-neighbor options without a compatibility alias.

Pair DataLoaders sort the selected Geometry Pair Set by global Coverage Similarity and snake-distribute the complete low-to-high ranking across all batches. Each batch therefore receives evenly spaced ranks spanning the distribution instead of a contiguous similarity region. Under DDP, ranks take disjoint strided slices of the global ordering before local snake distribution. The ordinary graph validation loader also uses disjoint shards and variable-size tail batches, so neither path pads evaluation data with duplicate samples. When pair tail-batch sizes differ across ranks, the optimization loss is scaled by local pair count over the global mean pair count before DDP gradient averaging, preserving pair-equal supervision. This batching policy creates within-batch target gaps for IoU ranking without requiring fixed absolute Jaccard intervals.
