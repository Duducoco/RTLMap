# Use typed true-volume subrectangles for coverage space

RTLMap represents each sample with five configurable-dimensional axis-aligned subrectangles, one for each coverage type. Current experiments use five dimensions per type. The geometry head reads the concatenated RTL and ASM graph summaries so test-stimulus information reaches the geometry output directly. A subrectangle's log true volume is supervised by the log coverage density without dividing the error by the box dimension. True-volume IoU uses an equal-type calibration loss plus a pairwise ranking loss over targets separated by a configured minimum Jaccard gap. Training may use a smooth intersection surrogate to retain gradients, while validation and inference always report hard geometric volume and IoU. This representation is trained from scratch and does not support loading legacy hyperrectangle weights.
